######################
v2.256.0 Model Updates
######################

The following model updates were made during the ``v2.256.0`` Synapse release.

*********************
Deprecated Properties
*********************

``biz:deal``
  The form had the following properties deprecated:


  ``buyer:org``
    Deprecated. Please use :buyer.


  ``buyer:orgfqdn``
    Deprecated. Please use :buyer.


  ``buyer:orgname``
    Deprecated. Please use :buyer.


  ``seller:org``
    Deprecated. Please use :seller.


  ``seller:orgfqdn``
    Deprecated. Please use :seller.


  ``seller:orgname``
    Deprecated. Please use :seller.
