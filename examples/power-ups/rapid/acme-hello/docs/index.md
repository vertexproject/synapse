# acme-hello

Acme-Hello is a minimal example of a Rapid Power-Up. This doc bundle is part of that example: it is
about the smallest set of pages a **Storm Package** can ship. The pages below are authored here in
`docs/` and built into `files/docs` by `synapse.tools.storm.pkg.doc`, so they travel with the package
like any other file it declares.

```mdtoc
userguide.md
adminguide.md
stormpackage.md
```
